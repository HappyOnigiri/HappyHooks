# 禁止語リストの書式

`forbidden-term-guard` は、リポジトリごとの禁止語リストに載っている語が PR や issue の本文に含まれていたら、送信を拒否する。
この文書はリストの置き場所と書式の仕様である。同じリストを読む他のツール（git の commit-msg / pre-push hook など）も、この仕様に合わせる。

## 置き場所

- 共通の git ディレクトリ（`git rev-parse --git-common-dir`）の直下に `forbidden-terms.txt` を置く。
  通常のリポジトリでは `.git/forbidden-terms.txt` になる。
- ファイルがあるリポジトリでだけ検査する（オプトイン）。無ければ何もしない。
- Git の管理外に置くのは、語そのものをどのリポジトリにもコミットさせないためである。
- linked worktree からも同じリストを使う。hook は git を起動せず、作業ディレクトリから親へ `.git` を辿り、
  `.git` ファイルの `gitdir:` と、その先の `commondir` を解決して共通の git ディレクトリを求める。

## 書式

- 文字コードは UTF-8。改行は `\n`・`\r\n`・`\r` のどれでもよい。
- 1 行に 1 語を書く。前後の空白は無視する。
- 空行と、`#` で始まる行は無視する。
- それ以外の行は、大文字小文字を区別しない部分一致で探す。記号も文字どおりに一致させる。
  大文字小文字の対応は Python の `re.IGNORECASE` に合わせ、`i`・`I`・`İ`・`ı` を互いに一致させる。
- `re:` で始まる行は正規表現として扱う（大文字小文字を区別しない）。`re:` の後ろの空白は無視し、中身が空の行は無視する。
  - 使える構文は、Go の RE2 と Python の `re` に共通する部分に限る。
    先読み・後読み・後方参照・所有的な量指定子など、片方にしか無い構文は書かない。
  - `\d`・`\w`・`\s`・`\b` は、hhx（RE2）では ASCII の範囲だけに一致し、Python では Unicode 全体に一致する。
    ASCII 以外の文字を含めたいときは、文字クラスで明示する。
  - 大文字小文字の対応は RE2 に従う。Python と違い、`i` は `İ`・`ı` に一致しない。必要なら文字クラスで明示する。
  - hhx は、コンパイルできない行が 1 つでもあれば、検査の対象のコマンドを行番号つきで拒否する。
    その語を検査できないまま送らないためである。リストを読む他のツールも、誤りとして報告する。
- 接頭辞の `re:` は小文字だけを認める。`Re:` で始まる行は、`Re:` を含めた文字どおりの語になる。

```text
# 社内の名称
acme-internal
re:acme[-_ ]?corp
```

## 検査する対象

- `gh pr create|edit|comment`、`gh issue create|edit|comment`、`gh api` のコマンド文字列。
- それらに `--body-file <path>`・`--body-file=<path>`・`-F <path>` で渡したファイルの中身。
  1 MiB を超えるファイル、読めないファイル、`-`（標準入力）は読まない。
  相対パスは payload の `cwd` を基準にする。
- 該当した行は、場所（`command` かファイルのパス）と行番号を付けて最大 10 件を理由文に出す。1 行は 200 文字で切る。

`git commit` と `git push` は対象にしない。git の commit-msg / pre-push hook で同じリストを使って検査する想定である。

コマンドの中の対象がすべて読み取りの `gh api` なら検査しない。別リポジトリの情報を引く要求では、語がそのリポジトリ名や org 名になるためである。
読み取りとみなすのは次のどれかである。

- `-X` / `--method` が `GET` のもの。
- `-X` / `--method` も `--input` も `-f` / `-F` も無いもの。
- エンドポイントが `graphql` で、`--input` が無く、フィールドの値に `mutation` を含まず、ファイルから読む値（`@path`）も無いもの。

`$(...)`・バッククォート・閉じない引用を含むコマンド、`gh` を別のコマンド越しに起動するもの、知らないフラグを渡したものは、読み取りと確かめられないので検査する。
