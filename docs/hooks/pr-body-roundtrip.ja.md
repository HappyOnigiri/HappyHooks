# pr-body-roundtrip

[English](pr-body-roundtrip.md) | 日本語 · [hook 一覧](../../README.ja.md#hook-一覧)

**既定:** Claude Code で有効。

Bash で `--body-file`（`-F`）を指定した `gh pr create` または `gh pr edit` が成功すると、hook はファイルと `gh pr view` で取得した本文を照合します。
CRLF と LF の違い、末尾の改行の違いは無視します。
本文が異なるときは unified diff の抜粋を示し、意図した本文を送り直して GitHub 上で確かめるようエージェントに促します。

`gh pr create` ではツールの出力から作成した PR の URL を取得します。
`gh pr edit` では指定した PR の番号・URL・ブランチを使い、指定を省いた場合は `gh` が現在のブランチから PR を探します。
`-R`（`--repo`）の指定を引き継ぎます。
コマンドの先頭が `cd` の場合は、絶対パスか `./` で始まる相対パスで、`..` を含まないときに移動先を使います。

コマンド・PR・ファイルを特定できないときや、`gh pr view` が失敗・タイムアウトしたときは無出力です。
標準入力から本文を渡す `--body-file -`、シェルの展開、添付ファイルのアップロードを使うコマンドは照合の対象外です。
hook はコマンド終了後にファイルを読むため、照合が済むまではファイルをそのまま残してください。
