# irreversible-guard

[English](irreversible-guard.md) | 日本語 · [hook 一覧](../../README.ja.md#hook-一覧)

**既定:** Claude Code と Codex で有効。

資格情報の失効、レジストリへの公開、リモートリソースの恒久削除、Git オブジェクトの破壊、ディスクやバックアップの消去など、ユーザーにも元に戻せない操作を止めます。`--dry-run` を付けた公開は通します。

`.env*`、`~/.ssh/*`、`*.pem` などの秘密ファイルへの書き込みと、`hhx` や hook の登録ファイルの削除・移動も止めます。秘密ファイルはシェルだけでなく編集ツールからの書き込みも調べます。

ファイルへ書き出すだけのヒアドキュメント（`cat > x.sh <<'EOF' ... EOF`）の本文は、そのコマンドの中では実行されないので調べません。書き出したファイルを同じコマンドで実行する場合や、シェルへ流し込む場合は本文も調べます。

該当する操作は拒否し、ユーザーへ報告するようエージェントに伝えます。`ask` は返しません。静的な検査なので、変数やスクリプト、別のシェルの中に隠れた操作をすべて検出できるわけではありません。
