# pr-body-edit-guard

[English](pr-body-edit-guard.md) | 日本語 · [hook 一覧](../../README.ja.md#hook-一覧)

**既定:** Claude Code と Codex で有効。

Bash の `gh pr edit` が送信しようとする本文に端末出力の特徴があれば、`gh pr view` で現在の本文を取得します。
現在の本文の最初と最後の非空行が、現在の本文と送信候補の両方で一意に見つかる場合に、それぞれの外側に追加された行を検査します。

検知するのは、生の ANSI 色制御シーケンス、診断ラベルに続くインデント付きのコマンドと使い方の案内2行、同じツール名で始まる連続した診断ログです。
Markdown の引用やコードフェンス内では、ANSI 色制御シーケンスを検査します。

拒否時には、該当行と検知理由を表示します。
意図した追記なら、拒否理由に表示された `HHX_PR_BODY_ACK=<sha256>` を `gh pr edit` の直前に付けて再実行してください。
ACK はそのときの本文のバイト列に対応するため、本文を変更すると再検査します。

対象は、Bash で直接実行し、`--body` に本文を記述するか、`--body-file` に実行前から存在するファイルのパスを書く呼び出しです。
PR の指定を省略した場合は、同じ作業ディレクトリで `gh` が解決します。
更新先や本文を特定できない場合、現在の本文を取得できない場合、または先頭・末尾の両方で比較の境界が見つからない場合は通します。
